# 演示脚本（约 3 分钟）

> 目标：让看的人在 3 分钟内明白“这是什么、解决什么问题、做得怎么样”。
> 录制工具：Windows 自带 Xbox Game Bar（Win+G）或 OBS。分辨率 1080p，别录声音外的杂音。

## 录制前准备

1. 启动服务：`powershell -ExecutionPolicy Bypass -File .\start.ps1`
2. 浏览器缩放到 100%，关掉无关标签页
3. 提前打开三个页面备用：首页、Agent 页、统计页
4. 想好要问的三个问题，别现场卡壳

## 分镜

### 0:00–0:20　开场

画面：浏览器停在问答页。

旁白：

> 这是一个本地运行的个人知识助手。它把 FastAPI 官方文档做成了可检索的知识库，支持带引用的问答、工具调用，以及用量统计。
> 整个项目单端口部署，一条命令启动。

### 0:20–1:05　RAG 问答

操作：输入「怎么给每个响应加一个处理时间的响应头？」

旁白：

> 中文提问、英文文档，系统会先把问题翻译成英文再检索——这是我们做的跨语言优化，把 recall@5 从 95% 提到了 100%。

等回答逐字输出完，鼠标指向底部的引用和指标：

> 回答里的 `[1]` 是出处编号，底部能看到命中文件和相似度。这一行是耗时和成本：大约 1.5 秒，0.0001 美元。

### 1:05–1:30　拒答

操作：输入「公司的年假政策是什么？」

旁白：

> 知识库里没有的问题，它会明确说“资料中没有相关信息”，不编造。这里有两层保护：检索分数低于 0.45 直接拒答、不调用模型；分数够但内容不够，模型会自己拒。

### 1:30–2:20　Agent

操作：切到 Agent 控制台，输入「查一下切块建议，写到 report.md，再读出来」。

旁白：

> Agent 部分用工具调用实现。模型自己决定调用顺序：先检索、再写文件、再读回来确认。

指向工具调用轨迹：

> 这里能看到每一轮的调用参数和返回结果。文件操作被限制在沙箱目录里，越界路径会被拒绝。

### 2:20–2:50　统计

操作：切到统计页。

旁白：

> 每次问答都会记录 token、成本和延迟，这里按天聚合。目前单次成本约 0.00015 美元。
> 这个数字决定了产品能不能规模化。

### 2:50–3:00　收尾

画面：回到 README 或架构图。

旁白：

> 项目用 FastAPI + React + SQLite，Docker 一键部署。评测方面有一套 20 题的检索集和 20 题的答案集，准确率 84%，拒答 5/5。

## 剪辑要点

- 去掉等待和打错字的片段，保留“逐字输出”的过程（这是流式的卖点）
