# AI 应用方向 · 学习工作区

这是你 24 周计划的代码与笔记仓库。规则只有四条：

1. **每学一个概念，48 小时内必须用进代码**，否则视为没学。
2. **每周至少一次公开输出**（博客 / 笔记 / 分享），写"我做了什么、数据如何"。
3. **每周日复盘**：对照 `weekN/README.md` 的验收标准打分，更新 `progress.md`。
4. **卡住超过 2 小时就换路**：查官方文档 → 问 AI → 找人，不要死磕。

## 目录

```
ai-journey/
├── README.md          # 你正在看的这个文件
├── progress.md        # 24 周打卡表
└── week1/             # 第 1 周：环境 + 第一次 API 调用
    ├── README.md      # 本周任务与验收标准
    ├── .env.example   # 密钥模板（复制成 .env，永不提交）
    ├── check_env.py   # 环境自检
    ├── first_call.py  # 第一次调用：手写 SSE 流式解析
    └── notes.md       # 学习日志
```

## 关于密钥

- 复制 `week1/.env.example` 为 `week1/.env`，填入你自己的 key。
- **`.env` 永远不要提交到 Git**（后面 W1 任务里会让你写 `.gitignore`）。
- 推荐先用 DeepSeek / 通义 / 智谱等国内 OpenAI 兼容接口，便宜、无需海外网络。
